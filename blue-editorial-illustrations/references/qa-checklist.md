# QA 与迭代清单

## 必过项

### 内容与构图

- [ ] 一张图只表达一个核心命题，1 秒内可读出主动作。
- [ ] IP 正在完成核心动作，不是旁观、指讲或装饰。
- [ ] 遮掉标注后，物件关系与状态变化仍能解释命题；去掉 IP 的动作后，关键转换不能照常成立。
- [ ] 环境和 3-7 个道具共同解释内容，没有无意义的填充物。
- [ ] 主体、手势、面部与主道具都在 HTML 安全留白之外。
- [ ] 没有把过往示例的桌面、卡片、动作或主物件原样复制到新主题。
- [ ] 桌面/工作台场景中，桌面是连续的前景遮挡平面；躯干不被桌沿切穿，腿脚在桌下地面层，手臂与桌面接触关系清楚。
- [ ] 图内短标注各自指向可见的动作、物件或结果，不占 HTML 安全留白，也不遮挡关键接触点。

### IP

- [ ] 侧分黑发、两个大圆镜框和小圆脸可识别。
- [ ] 两只眼睛分开，鼻梁间距清楚。
- [ ] 每只眼睛只有一个实心黑瞳孔；没有重复瞳孔、双虹膜或额外眼珠。
- [ ] 克莱因蓝翻领上衣、黑色宽裤和扁平小尖鞋存在。
- [ ] 脚不是三角支架、桌腿、厚底鞋或解剖脚趾。
- [ ] 多人场景中，每个 IP 都有清楚且不同的动作，但身份特征一致。

### 线条、色彩与体积

- [ ] 只有一个高饱和色相：克莱因蓝。
- [ ] 主轮廓有笔压变化和轻微手绘不规则，不像通用矢量素材。
- [ ] 蓝上衣在袖底、侧身或褶皱中至少有 2-3 块冷灰硬边结构面。
- [ ] 黑色宽裤保持黑色识别度，同时有约 15%-30% 冷灰折面，不是没有体积的纯色块。
- [ ] 面部、下颌、手臂和手部有克制的平涂灰面。
- [ ] 灰面沿形体暗部和折面连续组织，不像随机贴上的衣服补丁。
- [ ] 没有渐变、软阴影、光晕、拟真光影、空气喷涂或 3D 材质。

### 文件和 HTML

- [ ] 默认输出是 `2048x1152` PNG，或符合用户明确尺寸。
- [ ] 图内 1-4 个短手写标注与 shot list 的逐字文本一致，中文/英文没有错字、漏字或混用，缩略图下仍可读。
- [ ] 图内没有幻灯片标题、大段解释、无关文字、水印或 logo；字形与墨线、蓝色点染融为一体，不像 UI 标签。
- [ ] HTML 中的文字是真实文本，并严格落在 shot list 指定的安全留白中。
- [ ] 图片不被放在一张另外的装饰卡片内，页面不出现“卡片套卡片”。
- [ ] 在目标桌面和移动视口检查后，文字不压住脸、手和主道具。

## 失败分类与修正

| 失败 | 处理 |
| --- | --- |
| 重复瞳孔、鞋形或局部灰面错误 | 对已有成图做单一目标的定向编辑，同时附加 IP 身份参考，锁定其他区域 |
| 图内标注错字、漏字或脱离物件 | 优先定向修正一处文字并锁定其他标注；连续出错则缩短词语或减少标注后重生成 |
| 纯色块太多、线条过于矢量 | 保留构图，定向加入冷灰结构面和笔压变化 |
| 三角支架式脚部 | 局部修改为宽裤下方自然外伸的扁平小尖鞋 |
| 留白方向错、主体压到 HTML 文字区 | 重新生成构图，不用局部补丁强行挪动全局 |
| 视觉隐喻不成立或太像 PPT | 回到“判断 -> 动词 -> 物件 -> IP 动作”重写 shot list，再生成 |
| 出现新色相 | 定向去色，只保留黑白冷灰与 `#002FA7` |

## 交付标准

主 agent 必须亲自查看原尺寸和缩略图，不把子 agent 的“通过”当成最终验收。通过后向用户展示图片、用途和保存路径；最终视觉认可由用户决定。
