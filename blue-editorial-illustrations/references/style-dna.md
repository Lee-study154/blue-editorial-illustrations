# 风格 DNA

## 一句话

白底上的编辑漫画：有笔压变化的黑色墨线、克制的冷灰结构面和唯一的克莱因蓝，用夸张但易读的动作把抽象内容变成一个具体场景。

## 快速规格

| 维度 | 规则 |
| --- | --- |
| 画布 | 默认 `2048x1152`、16:9、纯白或近白背景 |
| 主色 | 目标克莱因蓝 `#002FA7`；抗锯齿和轻微明度变体可以存在，不得出现第二个色相 |
| 中性色 | 近黑、白、冷浅灰、中灰；不用暖褐灰或彩色灰 |
| 线条 | 黑色手绘墨线，粗细有变化，转折稍有不规则，局部重描 |
| 灰面 | 硬边平涂，用来说明袖底、侧身、褶皱、下颌、手臂和裤腿折面 |
| 材质 | 哑光墨水和平头画笔填色；边缘可略干、略抖，不做几何完美的矢量面 |
| 光影 | 只保留能解释体积的 2-3 级平面，不模拟真实光源 |
| 字形 | 1-4 个贴近物件/动作的短手写标注；黑墨为主，少量蓝色点染；中文有笔锋，英文偏手写展示衬线 |

## 绘图逻辑

- 主轮廓用稳定但不均匀的黑线，内部结构线更轻，动作线更自由。
- 大色块必须被冷灰结构面打断。蓝色上衣与黑裤不能是没有体积的整块纯色。
- 浅灰一般覆盖服装可见面积的约 15%-30%；黑裤仍然首先被读成黑色宽裤。
- 灰面沿袖底、侧缝、关节和裤腿折面连续组织；面积只作校准参考，不为凑比例添加孤立几何补丁。
- 面部只需一块下颌或侧脸灰面，手部用 1-2 块平面。不做皮肤渐变。
- 道具和环境共享同一笔触，但线密度低于人物，让 IP 始终是视觉中心。

## 颜色关系

1. 蓝色只出现在 IP 上衣、核心道具或关键结果中的 1-3 类元素。
2. 大面积白底提供呼吸感，黑色负责轮廓和重量，灰色负责体积，蓝色负责叙事焦点。
3. 不用蓝紫渐变、露出绿色/红色/黄色点缀，也不用蓝色阴影代替冷灰。

## 失败信号

- 线宽处处一致，边缘像矢量图标。
- 人物、桌子和卡片像通用 SaaS 插画库。
- 衣服和裤子是完整纯色块，没有冷灰结构面。
- 软阴影、光晕、渐变、高光光斑、3D 或拟真建模。
- 全画面铺纸纹、噪点或复古黄色滤镜。
