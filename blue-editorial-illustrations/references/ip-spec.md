# IP 角色规范

## 身份不变量

| 部位 | 必须保留 |
| --- | --- |
| 头发 | 黑色侧分头，一块主发结向前弯，轮廓简单 |
| 眼镜 | 两个大圆镜框，鼻梁间距清楚，线条可略不对称 |
| 眼睛 | 两只分开的白色椭圆眼；每只眼睛只有一个实心黑色小椭圆瞳孔 |
| 视线 | 默认略向上或朝当前操作对象，两个瞳孔方向一致 |
| 脸 | 小而偏圆，可用下颌冷灰面塑形，小 O 形嘴或简洁中性表情 |
| 上衣 | 简化的克莱因蓝翻领上衣，宽松袖子，硬边冷灰褶面 |
| 下装 | 黑色超宽长裤，裤管垂落，用中灰折面区分前后层 |
| 鞋 | 宽裤下方的扁平小尖鞋，左右自然向外伸，没有厚鞋底 |

## 眼部结构

圆镜框、眼白和瞳孔是三个分开的层级：

1. 外层是黑色圆镜框。
2. 镜片内是一只简单白色椭圆眼白。
3. 每只眼白内只放一个实心黑瞳孔。

不允许在单只眼内重复瞳孔、双重虹膜、高光形成的假瞳孔，或把鼻梁线误读为第二只眼。

## 比例和动作

- 头身比可夸张，但头部不应大到变成儿童卡通。
- 手臂可拉长，手掌可放大，用来让“整理、搬运、推拉、扶住、连接”等动作一眼可读。
- 鞋只是裤管底部的小型方向标，不画解剖脚趾、三角支架或金属支撑感。
- 每个画面先读出 IP 的动作，再读出道具和概念。IP 不站在旁边作为贴纸。

## 单人与多人

- 单人：IP 承担唯一核心动作。
- 双人：可以用两个 IP 实例表达交接、协作或对照；用姿态、道具和站位区分角色，不改掉身份特征。
- 多人：默认 3-5 个 IP 实例，使用前后层次和不同动作，不把人物排成证件照队列。
- 内容明确需要不同真实人物时，只让主角使用该 IP；其他人物简化为黑灰辅助角色。

## 输入规则

- 新生成时，将 `assets/ip-reference.jpeg` 作为身份参考自动传入。它不限制新场景的姿势和构图。
- 用户不需要每次重新提供或上传该 IP 文件。
- 已确认的示例只作低频本地对照，不默认上传到生图服务，避免复制它的桌面、卡片和动作。
- 修改已有成图时，第一张图是编辑目标，IP 图是身份参考；提示词必须列出锁定不变区域。
