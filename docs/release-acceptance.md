## 有意保留的差异

小黑换为自有眼镜 IP；红橙蓝改为唯一克莱因蓝和黑白冷灰；细线草图改为有笔压变化的彩绘编辑漫画；内置 image generation 改为外部 `gpt-image-2` CLI。HTML 文字安全区和独立英文 reference 是本项目明确增加的需求，不是上游原有前端框架。

## 发布前修正

清除私人机器路径和过时的待审核状态，修正新版实际 prompt 来源映射；英文 reference 已由用户确认。补齐新电脑的 CLI/provider/安全凭证前提与 dry run 说明。补充原创隐喻判断、整组命题去重和连续灰面规则，保留上游 attribution 与 MIT 原文，区分 IP/素材权利。

## 验证范围与残余风险

项目版、安装版与独立发布版均通过结构契约和 release 检查；独立发布版通过 skill YAML 校验，三份内容差异检查一致。行为试用仅规划新概念，不调用 API：验证中文/英文选择、局部编辑边界和新环境启动路由；最终窄范围复查已确认编辑输入契约和英文来源目录一致。实际打包后还须检查 ZIP 完整性与 SHA-256。

10 张参考图经 owner 确认的参考集收录；图片构图留白仍需在具体 HTML 中复核，部分画面下部道具延伸，不能保证整个左侧 40% 都可叠字。近似主题分别以“组织成稿/分拣归位”及“修复连接/验证交付”区分，后续新文稿需再次检查主题重复。

本次发布不重新付费生图，不代表验证了新账户的 API 余额或授权。生成式编辑不保证逐像素不变，测试通过不代替视觉 QA。HTML 演示另由执行 agent 实现和验收，仓库没有捆绑旧演示、私人日志、历史项目或其他 skill。
