# v1.0.0

首个正式版本：自有眼镜 IP、唯一克莱因蓝、黑色手绘墨线与冷灰体积，面向文稿和抽象概念的编辑漫画插画。

- 对齐 Ian Xiaohei Illustrations 的架构与核心转译逻辑：理解文稿、挑选认知锚点、发明物理隐喻、IP 完成动作、单张生成、QA 与定向修图。
- 收录 8 张中文 reference、2 张独立英文标题 reference，以及逐张对应的实际提示词；默认中文，明确要求时切换英文。
- 图内默认 1-4 个短手写标注，贴近动作、物件与结果；逐字校验，错字局部修图，不用 HTML 叠字冒充图内文字。
- 保留规划、整组生成、单概念与局部编辑四种模式，提供 HTML 文字安全区，不捆绑前端模板。
- 补齐可移植运行环境说明、素材来源映射、归属与权利声明，以及不调用 API 的自动检查。

## 安装

下载 `blue-editorial-illustrations-v1.0.0.zip`，解压后将其中的 `blue-editorial-illustrations/` 放入 Codex 的 skills 目录。安装包只含 skill，不含 Git 仓库或私人配置；校验值见同名 `.sha256` 附件。

## 运行边界

规划无需 API。生图使用运行时提供的 imagegen CLI 和外部 `gpt-image-2` provider（本项目已使用 ZenMux），不切换到 Codex 内置生图服务。需要 Python `openai` 依赖、支持编辑接口的 provider 与安全配置的凭证；已有本机配置直接复用。仓库不包含 API key、CLI 客户端或参考原图。

本轮发布验证不调用付费 API，不代表新账户余额或远端能力已测试。生成结果仍需视觉与文字 QA；具体 HTML 的加载、布局和安全区须另行验收。

上游改编部分保留 MIT 归属；自有 IP 与图像不自动获得 MIT 素材许可，公开展示不等于开放再发布授权。
