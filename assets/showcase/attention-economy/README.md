## Production roles

| Part | Responsibility |
| --- | --- |
| blue-editorial-illustrations | Character identity, physical metaphors, illustration planning and image generation |
| Separate video workflow | Script and storyboard, local character animation, real-page assets and camera movement, transitions, narration, mixing and rendering |

The video workflow adapts TalkCraft's explainer structure and page components, and uses OneTake's clearing case
as a reference for the cross-scale ending. Production boundaries and reproduction material are documented in
the [video workflow repository](https://github.com/Lee-study154/editorial-motion-video).
This illustration skill does not install those video tools or provide editing and narration on its own.
